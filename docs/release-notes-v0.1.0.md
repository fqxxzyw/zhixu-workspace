# 知序 v0.1.0 · 计算机学习工作台 Web MVP

当前交付为 Web 源码。包含知识空间与空账号引导、目录与分类、块笔记、图片标注、代码与 HTML 实验、思维导图、文件夹导入、Markdown / JSON 导出、评论与版本、个人 AI 配置、AI 草稿整理、知识卡片和复习。

Python 执行、离线账户和本地文件索引尚未交付。Windows 桌面版将使用本地账户和 SQLite；用户选择目录后建立索引与虚拟分类，不移动原文件。桌面 EXE 会单独发布并进行 Windows 验证。

发布前检查通过：TypeScript、Web 构建、知识工具验证以及临时 Worker / D1 / R2 集成测试。
