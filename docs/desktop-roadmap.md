# Windows 桌面版：本地账户与文件索引

状态：需求与实施规划，尚未交付 EXE。当前仓库中的 Web 上传与云端身份流程不作为桌面版的最终实现。

## 已确认的使用方式

1. Windows 安装器 EXE，安装后直接启动，不要求用户每天构建源码。
2. 使用本地服务与本地账户密码登录，账户和应用记录保存在本机。
3. 用户主动选择文件夹后才建立索引，不扫描整台电脑。
4. 索引保存路径、类型、时间及应用内分类。分类、标签、学科和快捷整理不改变原始文件的位置或名称。
5. 可以按真实磁盘目录浏览，也可以切换到按学科、标签、文件类别组织的虚拟目录。

## 与 Web 导入的明确区别

Web 的“导入”需要把文件内容上传到服务器；桌面版的“索引目录”记录本机文件的引用。将 `PyTorch/入门/train.py` 标到“优化器 / 代码”时，不会在磁盘上新建 code 目录，不会搬走、重命名或复制 `train.py`。

桌面版默认读取原文件。用户修改知识笔记、标注截图或生成 AI 总结时，生成的应用内容保存到应用资源目录；只有用户明确选择“写回原文件 / 导出到指定位置”，才修改或创建磁盘文件。写回前展示目标路径和差异，检查文件是否已被外部程序修改。

## 建议实现架构

候选交付路径为 Electron + 本地服务 + SQLite；最终依赖版本在实现阶段验证，不在此文档中假定已经安装或支持。

| 层 | 职责 |
| --- | --- |
| 桌面壳 | 窗口、安装、文件夹选择、文件打开、系统对话框 |
| 本地身份服务 | 首次设置账户密码、登录、锁定、会话与密码修改 |
| 本地知识存储 | 知识页、块、标签、评论、版本、复习和 AI 配置 |
| 文件索引服务 | 选定目录、层级索引、文件引用、增量刷新、失效引用 |
| 学习界面 | 复用块编辑器、代码预览、导图、HTML 实验和复习流程 |

优先使用受限 IPC 调用。如果使用 HTTP 服务，只绑定回环地址，设置会话/请求认证与来源验证，不暴露无鉴权的文件读取接口。渲染进程启用上下文隔离，默认不获得 Node.js 或任意文件系统访问权限。网页实验仍在隔离环境内运行。

## 本地账户

首次启动由用户设置账户与密码，不能内置默认账户。SQLite 中只保存带随机盐的密码哈希，不保存明文密码或可逆密码；登录会话与知识空间所有权关联。桌面版不依赖 ChatGPT 登录，也不伪造云端的身份请求头来模拟认证。

本地 AI Key 通过系统凭据能力或适当的本机加密保存，不复用仓库内的固定密钥。数据库与普通文件系统的访问控制也要明确：本地应用登录不能替代磁盘加密，拥有设备权限的人仍可能读取原文件。

## 文件索引数据模型（新增规划）

- `indexed_roots`：用户选择的目录、启用状态、扫描时间、忽略规则。
- `indexed_files`：目录 ID、绝对/相对路径、类型、大小、修改时间、可选内容指纹、可用状态。
- `file_classifications`：文件与学科、虚拟目录、标签的关联。
- `file_annotations`：针对原文件的笔记、图片标注、代码解释，保存于应用数据目录。

这些索引表与知识页面独立。一个文件可以关联多个专题；修改虚拟分类不触发磁盘文件操作。

## 索引行为

- 先展示原始层级树与文件类别，再支持用户自定义虚拟归类。
- 忽略依赖、缓存和版本管理目录；允许用户查看和修改忽略规则。
- 首次扫描可取消、可显示进度；后续按修改时间增量刷新，必要时再计算指纹。
- 外部文件新增/修改时刷新索引；丢失或删除的文件标记为“不可用”，保留已有笔记与分类，不静默删除知识。
- 外部移动文件后提示重新关联；指纹匹配作为建议，不未经确认替换引用。
- 软链接、目录循环、权限拒绝、超大文件、文件锁、中文路径、不同磁盘都需要处理。
- 搜索先支持文件名、路径、分类和知识笔记；正文提取按格式逐步扩展，不把“已建立索引”表述成“所有格式都已解析”。

## EXE 交付顺序与验收

1. 抽离身份、存储和资源接口，复用 Web 编辑功能，保持 Web 版本可用。
2. 实现 SQLite、本地账户、应用数据目录和本地 API Key 配置。
3. 实现目录选择、树形索引、虚拟分类、搜索和原文件打开。
4. 实现刷新、失效引用、应用内容备份与导出。
5. 在 Windows 上打包安装版，测试首次安装、登录、重启持久化、升级与卸载。

核心验收：索引前后原文件的路径、名称、大小、修改时间和内容指纹不变；取消扫描不损坏索引；重启后账户、分类和笔记仍在；失效文件不会使笔记消失；无网络时可以登录、浏览索引和编辑本地笔记。AI 与云端内容依其接口连接情况工作。

不在当前 Web Release 中放占位 EXE；只有经过 Windows 安装与运行验证后才作为桌面预览版发布。
