知序首个 Windows x64 桌面预览版。

下载 `Zhixu-Setup-0.2.0-x64.exe`，运行安装，首次启动设置本地账户与密码。新知识库为空，保留首次使用引导。

- 本地账户、SQLite 数据库与离线笔记，无需 ChatGPT 账号登录。
- 选择文件夹后建立索引，保留目录树；文件类别、学科、虚拟目录和标签独立整理，不移动、改名或修改原文件。
- 文件预览、定位原文件、刷新索引、缺失标记与关联学习笔记。
- 复用块级编辑、图片标注、代码、HTML 实验、思维导图、Markdown / JSON 导出、评论、历史、学习状态和复习。
- OpenAI 兼容 API 配置，支持本机 Ollama / LM Studio。API Key 加密保存，加密主密钥由 Windows 系统保护。

此版本每台安装仅一个本地账户；不提供云同步、跨电脑协作或密码找回。索引不递归符号链接；单目录上限 50,000 文件，列表最多显示 5,000；文本预览上限 2 MB。显式上传附件会保存到应用资源目录，与目录索引不同。Python 等代码不在应用内执行。

本版本未配置商业代码签名。Windows 可能提示未知发布者。可使用 `SHA256SUMS.txt` 校验安装包。

发布前自动执行本地数据流程测试、Windows 打包程序启动测试、安装后启动及本地账户重登测试；未覆盖所有 Windows 设备的人工体验验证。
