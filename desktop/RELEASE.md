# 知序 v0.3.0 · Fluent 桌面预览版

本次更新把仓库中的 Fluent 界面正式打入新的 Windows 安装包，同时修复文字溢出、切换卡顿和桌面外观偏好丢失。

## 下载

- **Zhixu-Setup-0.3.0-x64.exe**：Windows x64 完整安装器，可选择安装目录。
- **Zhixu-0.3.0-win-x64.zip**：包含 Electron 运行时与全部资源的完整程序目录。解压整个 ZIP 后运行 `知序.exe`，无需 Node.js。用户数据仍保存在应用数据目录，不随 ZIP 移动。
- **SHA256SUMS.txt**：上述两个文件的 SHA-256 校验值。

安装新版会继续使用已有本地知识库；首次使用需要设置本地账户。升级前可关闭应用并备份整个应用数据目录。

## 界面与体验

- 统一 Segoe UI Variable 系统字体栈、Fluent 图标、语义颜色、控件圆角、间距、焦点反馈和动效；左侧导航与右侧内容工作区分层。
- Windows 11 22H2 及以上使用原生 Mica 和系统标题栏按钮；高对比、减少透明度或不支持材质时回退纯色。菜单使用一致的纯色浮层。
- 浅色、深色、跟随系统、Windows 强调色和减少动画；桌面偏好写入本地文件，修复每次启动端口变化导致设置丢失。
- 设置默认打开外观偏好。弹窗固定标题与关闭按钮，内容独立滚动；历史、长路径、长链接、表格、代码和窄窗口工具栏分别约束溢出。
- 页面切换不再用整页截图覆盖控件，允许连续点击；搜索显示加载状态，旧请求不会覆盖新的查询。
- 索引列表每页 100 项，按目录、类别、学科或虚拟目录查看；目录树一次构建，深层缩进限制宽度。分类不移动或修改原文件。
- 代码高亮缓存计算；超过 100,000 字符或未知语言采用完整纯文本预览，避免自动语言检测阻塞操作。
- 首次窗口尺寸适应显示器工作区；重复启动恢复已最小化窗口；关闭未保存笔记时提供明确确认。

## 验证与边界

发布流程须通过类型检查、本地账户/数据库/文件索引/偏好持久化测试、真实服务上的 UI 测试、Windows 打包程序启动、静默安装和安装后启动检查，之后才公开 Release。UI 测试覆盖长内容、焦点恢复、键盘操作、230 项分页、360–1380px 布局和 100/125/150/200% 逻辑视口/DPR 组合。

截图和缩放模拟不等同于 Windows 11 实机 Mica、Snap 或多显示器 DPI 人工验收。当前是预览版，尚未配置代码签名；不提供云同步或密码找回。Python / Java / C++ 不在应用内执行；AI 使用用户自己的接口和密钥。原有本地笔记、索引、HTML 实验、导入导出与复习功能保留。
